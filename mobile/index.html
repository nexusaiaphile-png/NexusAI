NEXUSAI MOBILE ACTIVATION

Activate security from your phone.

For genuine camera activation, NexusAI pairs your phone directly with the Edge Agent on the same local network. Hikvision credentials stay on that Edge Agent.

Start secure mobile activation

On the computer connected to your Hikvision system, open the NexusAI Client Portal and start self-installation. A short-lived QR code will appear. Scan that QR code with this phone.

OPEN COMPUTER ACTIVATION
The QR pairing code expires quickly and can be used only once. After pairing, the phone can discover, verify and activate selected Hikvision cameras directly through the local Edge Agent.
