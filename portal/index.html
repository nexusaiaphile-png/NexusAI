THE WORKFLOW

One review flow. Two authorised data sources.

NexusAI correlates transaction exceptions with camera context so a retailer can investigate the relevant event more efficiently.

01 · POS DATA

Receive transaction exceptions

An authorised POS integration supplies exception events, such as refunds or voids when those event types are available from the retailer's POS system.

02 · CAMERA CONTEXT

Connect through HPP

With the retailer's authorisation, Hik-Partner Pro provides the supported site, device and camera context and available footage access.

03 · HUMAN REVIEW

Review the related footage

NexusAI links received exceptions to the relevant camera context and available footage for a person to review.

TECHNICAL READINESS

Designed to work alongside your existing systems.

A retailer assessment helps establish whether the required integrations and permissions are available.

  • A POS data feed or authorised integration that can provide the required transaction exception events.
  • Retailer authorisation for NexusAI to access the relevant Hik-Partner Pro site and camera context.
  • Suitable mapping between stores, tills and cameras, plus available footage for the event time.

HPP access alone does not generate POS refund or void records. NexusAI does not process refunds, replace the POS, or independently determine whether misconduct occurred.
